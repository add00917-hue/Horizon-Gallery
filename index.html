ตั้งค่า API Key
ใส่ Google Drive API Key เพื่อดึงภาพได้โดยตรง — ตั้งค่าครั้งเดียวบันทึกในเครื่อง
1
ไปที่ Google Cloud Console → Enable Google Drive API
2
Credentials → + CREATE CREDENTIALS → API key
3
ใน API key ที่สร้าง → API restrictions → เลือก Google Drive API → Save
4
แต่ละโฟลเดอร์ใน Drive → Share → Anyone with the link → Viewer
